# Огонь и Мясо — интернет-магазин

Одностраничный сайт магазина: шашлык, маринованное мясо, купаты, стейки из мраморной говядины, копчёности и соусы.
Каталог с поиском, корзина, выбор дня и времени получения, способа оплаты и отправка заказа в WhatsApp.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий (например, `meat-shop`), сделайте его **Public**.
2. Нажмите **Add file → Upload files** и загрузите `index.html` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/meat-shop/`.

## Что настроить

Все настройки — в начале блока `<script>` в `index.html`, раздел «НАСТРОЙКИ МАГАЗИНА»:

- `WA` — номер WhatsApp для заказов (сейчас `77055217933`).
- `FREE`, `DELIV`, `MIN` — порог бесплатной доставки, цена доставки, минимальный заказ (в тенге).
- `PAY` — ссылки на оплату: `kaspi.url` (Kaspi Pay) и `card.url` (оплата картой). Замените `ВАШ_КОД` и `ВАША_ССЫЛКА_НА_ОПЛАТУ` на свои.
- `SLOTS` и `PREP` — интервалы получения заказа и время на подготовку (в часах).

Товары и цены — в массиве `P` там же: категория, название, описание, цена, единица (`кг`, `шт`, `уп`), шаг количества и метка («Хит», «Новинка»).

Название, адрес, Instagram и часы работы меняются прямо в тексте страницы (блок «Контакты»).
